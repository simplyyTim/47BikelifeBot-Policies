## Maintenance

Update the documents here when the bot's actual data handling changes.
Do not commit bot tokens, API keys, credentials, logs, or operational data to
this public repository. The privacy policy currently uses the existing
47BikeLife community support contact. An actual responsible operator and
appropriate public contact details must be supplied by the operator; no legal
identity is inferred from a GitHub account.

The public URLs alone do not complete Discord verification. Configure the
links and team ownership in the Discord Developer Portal and complete its
remaining verification requirements.
